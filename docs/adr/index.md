# Architekturentscheidungen (ADR)

Jede Entscheidung ist ein `adr`-Need mit Status (`proposed`, `accepted`,
`superseded`, `deprecated`) und `decides`-Links auf betroffene Anforderungen
und Spezifikationen. Neue ADRs: Vorlage {doc}`vorlage` kopieren, nächste
Nummer vergeben.

```{needtable}
:types: adr
:columns: id, title, status, decides
:style: table
:sort: id
```
