# Anforderungen

Anforderungen sind als `req`-Needs erfasst. Jede Anforderung hat eine
MoSCoW-Priorität (`must`, `should`, `could`, `wont`) und einen Meilenstein
(`MVP`, `v1`, `v1.1`, `später`). Formulierung: *Das System muss/soll/kann …* plus
Akzeptanzkriterien.
